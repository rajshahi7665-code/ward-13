# 🏥 Ward 13 — Prologue

> A 2D atmospheric survival-horror game set inside an abandoned hospital.

## 🎮 About

**Ward 13** is a browser-based 2D survival-horror game.

You wake up inside a mysterious hospital where something has gone terribly wrong. Explore abandoned rooms, navigate dark corridors, discover what happened, and uncover the secrets hidden inside Ward 13.

This is the **Prologue** — the first playable version of the game.

## 🕹️ Controls

| Key | Action |
|---|---|
| WASD | Move |
| Arrow Keys | Move |
